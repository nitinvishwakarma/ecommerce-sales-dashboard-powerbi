# E-Commerce Sales Dashboard | Power BI

## Project Overview
[cite_start]This project features an end-to-end Power BI solution for tracking and analyzing retail performance across North America, managing a dataset of over **$11.53M in sales** and **$1.34M in profit**. [cite: 58, 74]

## Key Technical Features
- [cite_start]**Time Intelligence DAX:** Comparisons for YTD vs PYTD with dynamic trend indicators. [cite: 38, 74]
- [cite_start]**Advanced Ranking:** Implemented `RANKX` to identify Top 5 and Bottom 5 performing products. [cite: 38, 74]
- [cite_start]**Geographic Analysis:** Visualized regional sales distribution using latitude and longitude data. [cite: 38, 74]
- [cite_start]**Interactive UX:** Used Bookmarks and Slicers to create a seamless segment filtering experience (Consumer, Corporate, Home Office). [cite: 38, 74]

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- SQL Server (Data Cleaning)
